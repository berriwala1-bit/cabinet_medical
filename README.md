**Cabinet Médical** is a full-stack web application built for an academic project in **PHP**, designed to simplify daily clinic management, patient follow-up, appointment scheduling, and medical records.

## 💡 What This Project Demonstrates

* 🩺 **Clinic & Patient Management** — Centralized management of patients, consultations, and medical records in a clear web interface.
* 📅 **Appointment Scheduling** — Structured workflow to organize appointments and clinic activity efficiently.
* 🗄️ **Relational Database Architecture** — Structured **MySQL** schema connected via **PHP** to persist and query clinic data reliably.
* 🎓 **Academic Full-Stack Practice** — Clean separation of logic, database operations, and user-facing pages developed within a university/academic curriculum.
